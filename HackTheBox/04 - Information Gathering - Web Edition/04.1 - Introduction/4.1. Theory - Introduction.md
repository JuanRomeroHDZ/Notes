# Introduction
El *web reconnaissance* es  la base de una evaluación de seguridad exhaustiva. Realmente el proceso es muy parecido a los demás, simplemente cambia un poco el entorno.
Nos habla de que el proceso de *reconnaissance* es un proceso que se envuelve sistematicamente y meticulosamente para la recolección de información sobre un sitio web o aplicación web.
El apartado de *web reconnaissance* es parte del apartado de *Information Gathering*, tal cual con los servicios expuestos en un servidor.
![[Pasted image 20261113164012.png]]
El objetivo principal del *web reconnaissance* incluye:
	- **Identifying Assets (Identificación de activos)**: Descubrir todos los compentes publicamente accesibles del objetivo, tales como páginas web, subdominios, direcciones IP y tecnologías utilizadas. Este paso es de los más importantes ya que provee una amplia vista del objetivo.
	- **Discovering Hidden Information (Descubrimiento de información oculta)**: Localizar información confidencial que podría quedar expuesta de forma involuntaria, incluidos archivos de configuración, archivos de recuperación o documentación interna. Estos hallazgos pueden revelar información valiosa y pueden ser una puerta de entrada a proximos ataques.
	- **Analysis the Attack Surface (Análisis de la superficie de ataque)**: Examinar la superficie de ataque para identificar debilidades y vulnerables potenciales. Esto involucra evaluar la tecnología utilizada, configuraciones y posibles puntos de entrada para explotación.
	- **Gathering Intelligence (Recopilación de Información)**: Recolectar información que puede ser utilizado para una mayor explotación o ataques de ingeniería social. Esto incluye identificar claves personales, direcciones de correo, o patrones de comportamiento que podrían ser explotados.
