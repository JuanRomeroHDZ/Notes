# [[Academy Modules Layout]]
Este temario sirve como una hoja de ruta esencial, especialmente útil al desconocer el punto de partida ideal para el aprendizaje. El contenido estructura una secuencia lógica para abordar cada módulo de manera progresiva. Además, define la importancia técnica de cada sección, detallando los conocimientos clave que se obtendrán en cada etapa del proceso.

## [[Pre-Engagement]]
Esta fase es fundamental para obtener la información relevante antes de realizar cualquier evaluación de vulnerabilidades. Es el paso más importante del proceso, ya que reúne datos críticos, como direcciones IP y activos clave, necesarios para establecer una base sólida.

## [[Information Gathering]]
Antes de ejecutar cualquier ataque, es indispensable realizar una recolección e identificación de información. El cliente solo proporciona datos básicos, por lo que esta etapa es vital para expandir el conocimiento inicial y guiar los pasos posteriores.
![[Pasted image 20260622120721.png]]

### Técnicas y herramientas
* [[Network Enumeration with Nmap|Nmap]]: Detección de intrusos, firewalls, IPs y servicios.
* [[Footprinting]]: Identificación y examen de servicios para encontrar brechas.
* [[Information Gathering - Web Edition]]: Descubrimiento de estructuras en aplicaciones web.
* [[OSINT: Corporate Recon]]: Búsqueda de información pública (claves SSH, etc.).
