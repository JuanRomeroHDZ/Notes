# [[Penetration Testing]]
El [[Penetration Testing|Pentesting]] consiste en un ataque organizado con un objetivo claro: probar la infraestructura del área de [[TI]] para identificar [[Vulnerabilidad|vulnerabilidades]] y mejorar la seguridad.

## [[Risk Management]]
El departamento de [[TI]] se encarga de identificar, evaluar, analizar y mitigar riesgos que dañan la [[CIA triad|CIA]] (Confidencialidad, Integridad y Disponibilidad).

## [[Vulnerability Scanning Tools]]
* [[Nessus]]: Escaneador corporativo con una base de datos de firmas muy amplia. Ofrece reportes ejecutivos detallados y cuenta con versión gratuita ([[Nessus Essentials]]).
* [[Qualys]]: Plataforma [[Cloud Computing|cloud-based]] que utiliza agentes centralizados. Monitorea cumplimiento normativo (como [[PCI-DSS]]) en tiempo real.
* [[OpenVAS]]: Opción de [[Código abierto]] sin límite de [[IP]], ideal para consultores.

## [[Testing Methods]]
Existen dos enfoques principales según el punto de origen:
1. [[Internal Penetration Test]]: Se ejecuta desde dentro de la organización o aprovechando un sistema comprometido en la red interna.
2. [[External Penetration Test]]: Se enfoca en la parte externa, usualmente más vulnerable debido a la desinformación del usuario. Se recomienda proteger con [[IDS]], [[IPS]], [[Firewalls]] y alarmas.

## [[Types of Penetration Testing]]
El nivel de información disponible determina el tipo de prueba que puede realizarse:

| Tipo | Información proporcionada |
| :--- | :--- |
| [[Black Box]] | Mínima; únicamente se proporciona la [[Dirección IP|IP]] o los dominios del objetivo. |
| [[Grey Box]] | Parcial; incluye información como [[URL]], nombres de dispositivos o subredes. |
| [[White Box]] | Completa; proporciona acceso interno, configuraciones y credenciales. |
| [[Red Teaming]] | Simula un ataque real e incluye [[Ingeniería social]] y técnicas de ataque activo. |
| [[Purple Teaming]] | Enfoque colaborativo entre los equipos ofensivo y defensivo para mejorar la seguridad. |

## [[Testing Environments]]
Los atacantes aprovechan brechas en diversas categorías:
* **[[Infraestructura]]**: [[Network]], [[Host]], [[Server]].
* **[[Aplicaciones]]**: [[Web App]], [[Mobile]], [[API]], [[Thick Clients]].
* **Otros**: [[IoT]], [[Cloud Computing]], [[Source Code]], [[Physical Security]], [[Ingeniería social]], [[Security Policies]], [[Firewalls]], [[IDS]], [[IPS]].
