Hay que estudiar un poco, el protocolo FTP (File transfer protocol) corre en la capa de aplicación del modelo TCP/IP y el modelo OSI.
![[Pasted image 20261017171629.png]]
Siendo FTP uno de los más antiguos protocolos. Se encuentra en la misma capa de HTTP o POP. 
FTP necesita dos canales, una entrante y la otra saliente, esto lo hace mediante el puerto 21 de salida y el puerto 20 de entrada. FTP utiliza el puerto 21 para realizar la conexión, autenticación y el envio de comandos, mientras que el puerto 20 realiza la transferencia de archivos. Practicamente es como un jefe y un trabajados, el trabajador mueve los datos y el jefe controla aspectos teoricos/tecnicos.
Okay, interesante, por eso es qu utiliza TCP/IP, cuando hay algún error, este espera hasta poder reestablecer la conexión.
Okay, parece ser que FTP tiene dos variantes, *Pasivo y Activo* 
En la variante activa, el cliente establece la conexión vía TCP por el puerto 21, pero si se encuentra un firewall de parte del servidor, este bloqueará todo trafico. De este modo, se desarrolló la parte pasiva, donde el servidor realiza la conexión, es un tipo de reverse shell. El servidor expone un puerto y el cliente realiza la conexión a ese puerto, de esta manera no se bloquea nada de tráfico. Si, confirmado, es como si fuera un tipo de reverse shell.

## TFTP
Este tiene un significado un poco raro: *Trivial File Transfer Protocol (tftp)*, dice que es más simple que FTP. Dice que realiza transferencia de archivos entre procesos de cliente y servidor (no se a que se refiera). Este está peor que FTP, no provee nada de seguridad, ni para iniciar sesión ni para la transferencia. Okay, dice que es recomendado en archivos que pueden ser leidos y editados por todos.
Nos dejan algunos comandos de TFPT:

|**Commands**|**Description**|
|---|---|
|`connect`|Sets the remote host, and optionally the port, for file transfers.|
|`get`|Transfers a file or set of files from the remote host to the local host.|
|`put`|Transfers a file or set of files from the local host onto the remote host.|
|`quit`|Exits tftp.|
|`status`|Shows the current status of tftp, including the current transfer mode (ascii or binary), connection status, time-out value, and so on.|
|`verbose`|Turns verbose mode, which displays additional information during file transfer, on or off.|
TFTP no tiene el listado de directorios
## Default Configuration
De los servidores FTP uno de los más utilizados en distribuciones linux es vsFTPd. La configuración puede ser encontrada en */etc/vsftpd.conf*, y algunas de las configuraciones ya vienen predefinidas por default.
