Hay que estudiar un poco, el protocolo FTP (File transfer protocol) corre en la capa de aplicación del modelo TCP/IP y el modelo OSI.
![[Pasted image 20261017171629.png]]
Siendo FTP uno de los más antiguos protocolos. Se encuentra en la misma capa de HTTP o POP. 
FTP necesita dos canales, una entrante y la otra saliente, esto lo hace mediante el puerto 21 de salida y el puerto 20 de entrada. FTP utiliza el puerto 21 para realizar la conexión, autenticación y el envio de comandos, mientras que el puerto 20 realiza la transferencia de archivos. Practicamente es como un jefe y un trabajados, el trabajador mueve los datos y el jefe controla aspectos teoricos/tecnicos.
