MSSQL es una base de datos que fue desarrollada por Microsoft, obviamente es de codigo cerrado, por lo cual es diferente a MySQL, existen versiones MSSQL que se ejecutan en Linux y MacOS, pero lo más probable es que encontremos instancias MSSQL en sistemas que ejecutan Windows.
### MSSQL Clients
SQL Server Management Studio (SSMS) viene como una caracteristica que puede ser instalada con el paquete MSSQL  o puede ser descargado e instalado de manera independiente o individual.  Comunmente es instalado en el servidor para la configuración inicial y la gestión a largo plazo de las bases de datos por parte de los administradores. Teniendo eso en cuenta, desde que el SQL Server Management Studio (SSMS) es una aplicación del lado del cliente, puede ser instalado y utilizado en cualquier sistema en la cual un administrador o desarrollador está planeando administrar la base de datos. *No solamente existe el servidor que aloja la base de datos*, significa que podríamos encontrarnos con un sistema vulnerable con SSMS y credenciales guardadas que nos permitan conectarnos a la base de datos.
