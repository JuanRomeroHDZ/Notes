### Samba
SMB es un protocolo de red utilizado para compartir archivos, impresoras y otros recursos. Samba es una implementación de SMB para sistemas Linux y Unix, que permite interoperar con sistemas Windows. CIFS suele referirse a la versión antigua SMB 1.0, aunque el término continúa apareciendo en herramientas y documentación.

SMB puede funcionar directamente sobre TCP 445 o mediante NetBIOS sobre TCP 139. Los puertos UDP 137 y 138 se utilizan para servicios NetBIOS auxiliares. La elección del puerto no depende simplemente de que el servidor use Samba o Windows, sino de cómo esté configurado el transporte SMB.

|Puerto|Protocolo|¿Para qué sirve?|
|---|---|---|
|137|UDP|NetBIOS Name Service. Permite buscar nombres de equipos en una red NetBIOS.|
|138|UDP|NetBIOS Datagram Service. Permite enviar mensajes y datagramas mediante NetBIOS.|
|139|TCP|NetBIOS Session Service. Permite establecer una sesión de comunicación; antiguamente SMB lo utilizaba para compartir archivos.|
|445|TCP|SMB directamente sobre TCP, sin necesitar NetBIOS. Es el método habitual en SMB moderno.|
