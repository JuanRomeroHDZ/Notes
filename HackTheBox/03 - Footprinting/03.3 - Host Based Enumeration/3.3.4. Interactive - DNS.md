*Domain Name System (DNS)* es una parte integral de internet, es utilizado para traducir direcciones IP a nombres, en este caso nos ponen de ejemplo HackTheBox.com, para esto se utiliza la traducción de nombres de DNS. Osea, traduce IPs a nombres.
Interesante, yo pensé que solo existia un tipo de DNS, pero no, resulta que existen algunos más, como:
- DNS root server
- Authoritative name server
- Non-authoritative name server
- Caching server
- Forwarding server
- Resolver

Acá más información de cada uno

| Server Type                  | Description                                                                                                                                                                                                                                                                                                                   |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DNS Root Server              | Es encargado del TLD (top-level domains), como la ultima instancia, son requeridos si el servidor no responde, tal vez cuando existe un nombre pero no una IP o viceversa. De este modo, un servidor raiz es una interfaz central entre los usuarios y el contenido en internet. Ya que enlazan dominios y direcciones IP.    |
| Authoritative Nameserver     | Tienen la autoridad para una zona en particular. Solamente responden consultas relacionadas a su área de responsabilidad, y la información que proporcionan es vinculante. Si un servidor de nombres autoritativo no puede responder a la consulta de un cliente, el servidor de nombres ráiz toma el control en ese momento. |
| Non-authoritative nameserver | Ellos no son responsables de una sola zona en particular, en su lugar, recolectan información de una zona en especifico para ellos mismos, el cual se realiza mediante consultas DNS recursivas o iterativas.                                                                                                                 |
| Caching DNS Server           | Obtiene información de otros DNS de un periodo especifico, el DNS authoritative determina la duración del almacenamiento.                                                                                                                                                                                                     |
| Forwarding Server            | Solamente tiene una función; Reenvian las peticiones a otro servidor DNS                                                                                                                                                                                                                                                      |
| Resolver                     | Estos no son servidores DNS autoritativos, sino que realizan la resolución de nombres localmente en el PC o el router.                                                                                                                                                                                                        |

Para las consultas DNS se utilizan diferentes registros DNS, cada uno con funciones distintas, además, existen entradas separadas para diferentes funciones, ya que podemos configurar servidores de correo y otros servidores para un dominio.

| DNS Record | Description                                                                                                                                                                                                                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A          | Devuelve como resultado una dirección IPv4 del dominio solicitado                                                                                                                                                                                                                                            |
| AAAA       | Devuelve una dirección IPv6 del dominio solicitado                                                                                                                                                                                                                                                           |
| MX         | Devuelte los servidores de correo responsables como resultado                                                                                                                                                                                                                                                |
| NS         | Devuelte los servidores DNS (servidores de nombres) de dominio.                                                                                                                                                                                                                                              |

| CNAME      | Este registro sive como un alias para otro nombre de dominio. Si quisieramos por ejemplo, el dominio *www.hackthebox.eu* apuntando a la misma IP como *hackthebox.eu*, deberiamos crear un registro A para *hackthebox.eu* y un registro CNAME para *www.hackthebox.eu*                                      |

Convierte las direcciones IP a  a nombres de dominio validos                                                                                                                                                           |

## Default Configuration
Hay muchos tipos de configuración de DNS, por lo tanto, solo se discutirá unos de los más importantes para mostrar mejor el principio funcional  desde un punto de vista administrativo.  Todos los servidores DNS funcionan con tres diferentes tipos de archivos de configuración:
1. Archivos locales de configuración DNS
2. Archivos de zona
3. Archivos de resolución de nombres inversa
El servidor DNS Bint9 a menudo es muy utilizado en distribuciones Linux. Su archivo de configuración *(named.conf)* se divide aproximadamente en dos secciones: primero, la sección de opciones para la configuración general y segundo, las entradas de zona para los dominios individuales. Los archivos de configuración local suelen ser:
- named.conf.local
- named.conf.options
- named.conf.logs
Contiene el RFC asociado donde podemos personalizar el servidor según nuestras necesidades y nuestra estructura de dominio, con zonas individuales para diferentes dominios. El archivo de configuración *named.conf* está dividido en varias opciones que controlan el comportamiento del servidor de nombres. Se establece una distinción entre opciones globales y opciones por zonas.
Las opciones globales son generales y afectan a todas las zonas. Una opción de zona solo afecta a la zona a la que está asignada. Las opciones que no aparecen en *named.conf* tienen valores predeterminados. Si una opción es global y especifica de una zona, prevalece la opción de zona.
