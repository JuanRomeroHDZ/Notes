*Domain Name System (DNS)* es una parte integral de internet, es utilizado para traducir direcciones IP a nombres, en este caso nos ponen de ejemplo HackTheBox.com, para esto se utiliza la traducción de nombres de DNS. Osea, traduce IPs a nombres.
Interesante, yo pensé que solo existia un tipo de DNS, pero no, resulta que existen algunos más, como:
- DNS root server
- Authoritative name server
- Non-authoritative name server
- Caching server
- Forwarding server
- Resolver

Acá más información de cada uno

| Server Type                  | Description                                                                                                                                                                                                                                                                                                                   |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DNS Root Server              | Es encargado del TLD (top-level domains), como la ultima instancia, son requeridos si el servidor no responde, tal vez cuando existe un nombre pero no una IP o viceversa. De este modo, un servidor raiz es una interfaz central entre los usuarios y el contenido en internet. Ya que enlazan dominios y direcciones IP.    |
| Authoritative Nameserver     | Tienen la autoridad para una zona en particular. Solamente responden consultas relacionadas a su área de responsabilidad, y la información que proporcionan es vinculante. Si un servidor de nombres autoritativo no puede responder a la consulta de un cliente, el servidor de nombres ráiz toma el control en ese momento. |
| Non-authoritative nameserver | Ellos no son responsables de una sola zona en particular, en su lugar, recolectan información de una zona en especifico para ellos mismos, el cual se realiza mediante consultas DNS recursivas o iterativas.                                                                                                                 |
| Caching DNS Server           | Obtiene información de otros DNS de un periodo especifico, el DNS authoritative determina la duración del almacenamiento.                                                                                                                                                                                                     |
| Forwarding Server            | Solamente tiene una función; Reenvian las peticiones a otro servidor DNS                                                                                                                                                                                                                                                      |
| Resolver                     | Estos no son servidores DNS autoritativos, sino que realizan la resolución de nombres localmente en el PC o el router.                                                                                                                                                                                                        |
Normalmente el servidor DNS no está cifrado. Los dispositivos en una red WLAN local y los proveedores de internen pueden piratear y espiar las consultas DNS. Dado estas debilidades, se suele utilizad DNS sobre TLS (DoT) o DNS sobre HTTPS (DoH). Además, el protocolo de red DNSCrypt también cifra el tráfico entre el ordenador y el servidor de nombres.
