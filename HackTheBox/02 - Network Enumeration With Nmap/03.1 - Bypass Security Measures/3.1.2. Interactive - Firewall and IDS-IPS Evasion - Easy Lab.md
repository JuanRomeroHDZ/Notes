## Recursos
IP: 10.129.216.100
Para este escaneo nos advierten de que debemos de tener cuidado, nos dan hasta 100 packetes para gastar antes de ser baneados por tres segundos. 
Utilicé el siguiente comando de Nmap:
```nmap
sudo nmap -v --disable-arp-ping --osscan-limit --source-port=53 -D RND:10 -T 1 -Pn -n -sA/-sS
```

| Flag               | Significado                                                                                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| -v                 | Verbose, para ver lo que pasa en tiempo real                                                                                                            |
| --disable-arp-ping | Se desactiva el escaneo ya que sabemos que el host está activo, ayuda a descubrir los hosts más rápido                                                  |
| --osscan-limit     | Hace el intento de recuperar el nombre del sistema operativo mediante los servicios                                                                     |
| --source-port=53   | Quita el escaneo UDP 53 y utiliza el escaneo TCP 53                                                                                                     |
| -D RND:10          | Utiliza 10 IPs diferentes para realizar el escaneo                                                                                                      |
| -T 1               | Realiza un escaneo sigiloso, pero actualmente es predescible ya que lo hace periodicamente                                                              |
| -Pn                | Deja de hacer conexiones mediante ping, ya que sabemos que el host está activo                                                                          |
| -n                 | Quita la resolución DNS ya que realizamos el escaneo por IP                                                                                             |
| -sA/-sS            | Es un paquete que utiliza para sacar información, en algunos más fuertes puede sacar información más sensible, pero suelen ser más agresivas y ruidosas |
