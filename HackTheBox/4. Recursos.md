## Herramientas Utilizadas

Hemos utilizado las siguientes herramientas, incluyendo editores de texto, multiplexores, etc:
1. nmap
	1. Herramienta local
	2. Herramienta de escaneo avanzado
2. smbclient
	1. Herramienta local
	2. Protocolo de transferencia, normalmente utilizado en impresoras
3. GoBuster
	1. Herramienta local
	2. Descubrimiento de archivos/directorios ocultos en un servidor web
4. Curl
	1. Herramienta local
	2. Nos sirve para extraer algo que querramos de una página web
5. exploitdb
	1. Página web
	2. Nos permitirá realizar la busqueda de algún exploit para alguna versión de algún servicio
6. MSF (metasploit framework)
	1. Herramienta local
	2. Utilzado para ejecutar scripts y realizar ataques de prueba sin vulnerar a un objetivo, tiene más funciones.
7.  Enumeración
	1. Herramienta local
	2. Se encuentra en la ruta de /HackTheBox/Recursos/1.Enumeracion_Linpeas.sh
8. Pending
