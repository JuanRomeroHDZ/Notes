
| **Categoría**         | **Flag**               | **Nombre / Significado**              | **Descripción técnica**                                                                                                                                                                                     |
| --------------------- | ---------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Descubrimiento**    | `-sn`                  | _No port scan_ (Ping scan)            | Determina si el objetivo está activo enviando sondas ICMP, SYN TCP (443) y ACK TCP (80) sin realizar escaneo de puertos.                                                                                    |
| **Descubrimiento**    | `-Pn`                  | _No Ping_ (Treat all hosts as online) | Omite la fase de descubrimiento previo y asume que el host está activo; indispensable contra hosts que descartan paquetes ICMP/Echo.                                                                        |
| **Descubrimiento**    | `-n`                   | _No DNS resolution_                   | Deshabilita la resolución inversa de DNS para cada IP encontrada, reduciendo drásticamente el tiempo total del escaneo.                                                                                     |
| **Descubrimiento**    | `-PR`                  | _ARP Ping_                            | Utiliza solicitudes ARP para descubrir hosts en la misma red local (subred Layer 2), siendo mucho más rápido y certero que ICMP.                                                                            |
| **Tipo de Escaneo**   | `-sS`                  | _TCP SYN Scan_ (Stealth scan)         | Envía un paquete SYN y espera la respuesta; si recibe SYN/ACK envía un RST en lugar de completar el handshake TCP, reduciendo el registro en logs tradicionales. _(Requiere privilegios root/admin)_.       |
| **Tipo de Escaneo**   | `-sT`                  | _TCP Connect Scan_                    | Completa el protocolo de enlace de tres vías (`SYN -> SYN/ACK -> ACK`) mediante llamadas del sistema del SO; es la alternativa por defecto cuando no se tienen privilegios de superusuario.                 |
| **Tipo de Escaneo**   | `-sU`                  | _UDP Scan_                            | Envía paquetes UDP vacíos a puertos de destino; si el puerto no responde, se asume `open\|filtered`, y si recibe un paquete ICMP tipo 3 (puerto inalcanzable), se marca como cerrado. Es más lento que TCP. |
| **Tipo de Escaneo**   | `-sA`                  | _TCP ACK Scan_                        | Envía paquetes ACK para mapear reglas de firewall o routers perimetrales; determina si los puertos están filtrados o sin filtrar en función de las respuestas RST.                                          |
| **Selección Puertos** | `-p <rango>`           | _Port range specification_            | Escanea únicamente los puertos indicados (ej. `-p 80,443`, `-p 1-1000`, `-p U:53,T:21-25`).                                                                                                                 |
| **Selección Puertos** | `-p-`                  | _All ports_                           | Atajo para escanear todo el rango de puertos válidos de TCP o UDP (`1` al `65535`).                                                                                                                         |
| **Selección Puertos** | `-F`                   | _Fast scan_                           | Limita el escaneo a los 100 puertos más comunes según el archivo interno `nmap-services`.                                                                                                                   |
| **Selección Puertos** | `--top-ports <n>`      | _Top ports_                           | Escanea los _n_ puertos más comúnmente abiertos en internet de acuerdo con las estadísticas de Nmap (ej. `--top-ports 500`).                                                                                |
| **Detección**         | `-sV`                  | _Service/Version Detection_           | Interroga los puertos abiertos enviando firmas de sondeo para extraer el banner, el software exacto y la versión en ejecución.                                                                              |
| **Detección**         | `-O`                   | _OS Detection_                        | Envía una serie de paquetes TCP e IP modificados para analizar las respuestas de la pila de red del objetivo y deducir su sistema operativo exacto.                                                         |
| **Detección**         | `-A`                   | _Aggressive Scan_                     | Habilita un conjunto compuesto de herramientas avanzadas: detección de SO (`-O`), versiones de servicios (`-sV`), escaneo de scripts predeterminados (`-sC`) y traceroute (`--traceroute`).                 |
| **Rendimiento**       | `-T0` a `-T5`          | _Timing Template_                     | Define perfiles de agresividad temporal: `T0` (Paranoid) y `T1` (Sneaky) para evadir IDS, `T3` (Normal por defecto), y `T4` (Aggressive) o `T5` (Insane) para redes rápidas y confiables.                   |
| **Rendimiento**       | `--min-rate <n>`       | _Minimum packet rate_                 | Fuerza a Nmap a no enviar paquetes a una tasa menor de _n_ paquetes por segundo, acelerando escaneos masivos a costa de precisión en redes congestionadas.                                                  |
| **Scripts (NSE)**     | `-sC`                  | _Default Script Scan_                 | Ejecuta el conjunto básico de scripts Lua no intrusivos de la categoría _default_ para recopilar información común del servicio. Equivale a `--script=default`.                                             |
| **Scripts (NSE)**     | `--script <cat/name>`  | _Script selection_                    | Ejecuta scripts o familias de scripts específicos del Nmap Scripting Engine (ej. `--script vuln`, `--script http-title`, `--script smb-os-discovery`).                                                      |
| **Evasión**           | `-f`                   | _Fragment packets_                    | Fragmenta los encabezados IP en paquetes diminutos de 8 bytes para dificultar que los cortafuegos y sensores de inspección profunda reensamblen la firma del escaneo.                                       |
| **Evasión**           | `-D <señuelo1,ME,...>` | _Decoy scan_                          | Mezcla la dirección IP real del atacante con múltiples direcciones IP señuelo ficticias para saturar los registros del sistema de detección de intrusos.                                                    |
| **Evasión**           | `-S <IP>`              | _Source IP spoofing_                  | Suplanta la dirección IP de origen en los encabezados del paquete; requiere capturar el tráfico por otra vía o usarlo en escaneos ciegos.                                                                   |
| **Evasión**           | `-g` / `--source-port` | _Source port manipulation_            | Fuerza a Nmap a enviar el tráfico desde un puerto de origen específico (ej. puerto 53 o 88), evadiendo firewalls con reglas permisivas hacia tráfico de servicios confiables.                               |
| **Salida**            | `-oN <archivo>`        | _Output Normal_                       | Guarda el reporte con el formato legible idéntico al que se imprime por la terminal.                                                                                                                        |
| **Salida**            | `-oX <archivo>`        | _Output XML_                          | Genera el informe estructurado en XML, el estándar utilizado para importar resultados a herramientas como Metasploit, DefectDojo o Nessus.                                                                  |
| **Salida**            | `-oA <prefijo>`        | _Output All Formats_                  | Genera simultáneamente el reporte en los tres formatos principales (`.nmap`, `.xml` y `.gnmap` para grep).                                                                                                  |
| **Diagnóstico**       | `-v` / `-vv`           | _Verbosity level_                     | Incrementa el nivel de detalle en pantalla en tiempo real, mostrando puertos abiertos tan pronto como son descubiertos.                                                                                     |

---

| Categoría     | Explicación                                                                                                                                                                                                                                           | Ejemplo                                                                                                                                    |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **default**   | Scripts que se ejecutan automáticamente con `-sC`. Recogen banners, títulos HTTP, keys SSH, certificados SSL y accesos anónimos básicos. Rápidos, no destructivos y con poca generación de ruido. Si no especificas `--script`, nmap asume `default`. | `nmap -sV -sC -p 80,443 target` → Ejecuta `http-title`, `http-headers`, `ssl-cert`, `ssh-hostkey`, etc.                                    |
| **safe**      | Garantizan cero efecto negativo: no consumen recursos, no generan tráfico inusual, no modifican estado. Son estrictamente read-only. Subconjunto más amplio que `default` pero igualmente inofensivo.                                                 | `nmap --script safe -p 80,443 target` → Incluye `default` más `http-robots.txt`, `dns-service-discovery`, `ldap-rootdse`, etc.             |
| **discovery** | Enumeración profunda: subdominios, rutas de directorio, shares SMB, interfaces SNMP, usuarios, topología de red. Más lentos (múltiples peticiones) y pueden ser detectados por IDS. La categoría más usada en fase de enumeración.                    | `nmap --script "discovery and safe" -p 80,443,445 target` → `http-enum`, `smb-enum-shares`, `dns-brute`, `snmp-interfaces`, `ldap-search`. |
| **version**   | Solo se ejecutan bajo `-sV`. Extienden el fingerprinting con métodos HTTP, algoritmos SSH, puertos de proxy, etc. No corren si no usas `-sV`.                                                                                                         | `nmap -sV -p 80 target` → `http-methods`, `http-server-header`, `ssh2-enum-algos`.                                                         |
| **broadcast** | Envían paquetes broadcast/multicast para descubrir hosts no listados. Con `newtargets` los agregan al scan automáticamente. Requieren estar en la misma subred.                                                                                       | `nmap -sP --script broadcast-dhcp-discover --script-args newtargets 192.168.1.0/24`                                                        |
| **malware**   | Detectan si el target ya está comprometido: backdoors conocidos, daemons spoofing, puertos SMTP inusuales. Solo identifican patrones, no explota.                                                                                                     | `nmap --script malware -p- target` → `smtp-strangeport`, `auth-spoof`, `http-malware-domains`.                                             |
| **external**  | Consultan servicios de terceros: whois, geoip, bases CVE (Vulners, NVD), DNS blacklist. **Leak** que estás escaneando esa IP. Lentos por peticiones HTTP externas.                                                                                    | `nmap --script external -p 80 target` → `vulners`, `dns-blacklist`, `whois`.                                                               |
| **auth**      | Prueba credenciales por defecto, accesos anónimos o bypass de autenticación **sin** fuerza bruta. SNMP `public`, FTP anónimo, X11 sin password. No lanza diccionarios.                                                                                | `nmap --script auth -p 22,445,161 target` → `ftp-anon`, `snmp-interfaces`, `x11-access`.                                                   |
| **brute**     | Fuerza bruta real con wordlists contra SSH, FTP, HTTP, MySQL, RDP, etc. Genera muchos logs, puede bloquear cuentas (fail2ban) y es muy detectable. Último recurso.                                                                                    | `nmap --script ssh-brute --script-args userdb=users.txt,passdb=rockyou.txt -p 22 target`                                                   |
| **vuln**      | Checan CVEs y vulnerabilidades conocidas. Solo imprimen si **encuentran** algo. No explota: solo confirma. La categoría clave en vulnerability assessment.                                                                                            | `nmap --script vuln -p 443 target` → `ssl-heartbleed`. `nmap --script vuln -p 445 target` → `smb-vuln-ms17-010`.                           |
| **intrusive** | Pueden afectar negativamente: consumen ancho de banda, generan tráfico anómalo, causan timeouts o son detectados como ataque. No necesariamente tumban el servicio pero lo estresan. Solo en lab o con autorización explícita.                        | `nmap --script http-slowloris -p 80 target` → Agota el pool de conexiones del servidor.                                                    |
| **exploit**   | **Explotan activamente** la vulnerabilidad: ejecutan código, suben archivos, confirman RCE. La categoría más peligrosa. Puede dejar el sistema inestable. Solo en lab con autorización escrita.                                                       | `nmap --script http-fileupload-exploiter -p 80 target` → Sube un archivo para confirmar file upload.                                       |
| **dos**       | Pruebas de denegación de servicio: floods, paquetes malformados en volumen, exhaustan recursos. **Pueden dejar el target caído** hasta reinicio. Casi nunca se usa en pentests reales.                                                                | `nmap --script dos -p 80 target` → `http-slowloris`, floods UDP.                                                                           |
| **fuzzer**    | Envían datos malformados/aleatorios/extremos al servicio para encontrar crashes o bugs de parsing. Lento y disruptivo. Útil en lab para 0-days, casi inútil en pentesting real.                                                                       | `nmap --script http-form-fuzzer -p 80 target` → Envía valores extremos en cada campo de un formulario.                                     |
