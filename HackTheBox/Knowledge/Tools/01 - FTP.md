| Tool  | Use                                                                      |
| ----- | ------------------------------------------------------------------------ |
| ftp   | Conectarte manualmente, probar credenciales y descargar archivos.        |
| nmap  | Detectar FTP, identificar versión y comprobar si permite acceso anónimo. |
| curl  | Interactuar con FTP desde la terminal y descargar archivos.              |
| lftp  | Cliente más completo para listar, navegar y transferir archivos.         |
| hydra | Auditar credenciales FTP mediante fuerza bruta, cuando esté autorizado.  |
