## Ejercicio
Bueno, para el ejercicio se realizará la enumeración de las paginas, algunas estarán ocultas y será necesario entrar a rutas para encontrarlas, para esto utilizaré Gobuster.

### Pasos
1. Realizar la busqueda de puertos que tiene expuesto la IP 10.129.196.219
Para eso utilizaré Nmap.
```text
nmap -Pn -v -sV -sC --min-rate 5000 [IP]
```
![[Pasted image 20260913124831.png]]
Como podemos observar, tiene el puerto 80 abierto con el servicio Apache con la versión 2.4.18.
Indagaré si tiene una vulnerabilidad con searchsploit.
```text
searchsploit "httpd 2.4.18"
```
![[Pasted image 20260913125145.png]]
Como podemos observar existe un exploit, pero es simplemente para DoS, y nosotros buscamos ganar acceso a los recursos del sistema, por lo cual no nos será útil.
Pasaremos a Gobuster
```text
gobuster dir -u http:10.129.196.219 -w [directorio que no recuerdo] -t 20
```
![[Pasted image 20260913125737.png]]
Como podemos observar encontramos que solo podemos acceder a /index.html, para eso lo que haré será obtener más información con curl
```text
curl -s http://10.129.196.219/index.html
```
![[Pasted image 20260913125925.png]]
Como podemos observar nos dice que ese no es el directorio principal, por lo cual habrá que indagar nuevamente con Gobuster en el directorio /nibbleblog/
```text
gobuster dir -u http://10.129.196.219/nibbleblog/ -w [x/x/common.txt] -t 30
```
