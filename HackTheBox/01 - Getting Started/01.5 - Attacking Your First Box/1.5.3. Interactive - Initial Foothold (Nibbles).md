# Nibbles - Initial Foothold
Nos habla de que hemos logrado acceder al portal de administración pero ahora necesitamos lograr acceder al sistema, se habla de una reverse shell, supongo que será el metodo que utilizaremos, posiblemente con metasploit busquemos una vulnerabilidad en la cual se base subir un archivo en la cual la victima inicie la comunicación. Aún no sé que es lo que pasará pero haremos uso de algunas de estas herramientas.

---
Realmente fue muy interesante porque efectivamente se trataba de realizar un hacking utilizando una reverse shell. En este caso aprovechamos una vulnerabilidad que tenía la pagina de administración en la cual nos permitía subir una "imagen" con cualquier formato y este lo ejecutaba en el servidor. Subimos un archivo con formato .php, en el cual el archivo contenia el codigo para la reverse shell.
Se le modificó al archivo la IP ya que se ponía la del atacante (La nuestra) y el puerto en el cual el servidor iba a intentar conectarse, en ese caso fue el puerto 36936.
Para la parte del atacante se utilizó el siguiente comando:
```bash
nc -lvpn 36936
```
El significado de cada tag lo tengo en otro archivo, pero en pocas palabras es que netcat se pone en modo escucha mientras que cada acción se va mostrando en la pantalla por el puerto 36936 y la n nos sirve simplemente para omitir la resolución de dns, osea, busca por IP en lugar de un nombre.
Una vez que nos quedamos en modo escucha en ese puerto, es necesario activar la acción del reverse shell. Para que se active es necesario que el recurso sea activado o requerido, para eso haremos un curl al archivo que subimos.
```bash
curl [Dirección del recurso a activar]
```
Con eso ganamos acceso a la terminal de la maquina de la victima.
Sin embargo, no se pueden realizar todas las acciones que querramos, necesitamos hacer un "*upgrade*" a esa terminal, para eso utilizaremos el siguiente código:
```bash
python3 -c 'import pty; pty.spawn("/bin/bash")'
```
Con eso deberíamos de tener acceso a la terminal, y ya con el navegar a donde querramos.
Al final el archivo que buscabamos se encontraba en la ruta
```
/home/nibbles/flag.txt
```
