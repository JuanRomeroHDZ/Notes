# [[Network Layer Troubleshooting|Resolución de Problemas en la Capa de Red]]
La [[Network Layer|Capa de Red]] (Capa 3) es la responsable del direccionamiento lógico y del enrutamiento de los paquetes a través de diferentes subredes. Las fallas en este nivel no se limitan a la conectividad local, sino que impactan directamente en la capacidad de los datos para alcanzar destinos remotos, internet o servicios en la nube.

Al diagnosticar la Capa 3, cruzamos los siguientes síntomas operativos con sus causas más probables:

 
| Síntoma Detectado en la Red | Posible Causa Raíz (Capa 3) | Herramienta o Comando de Validación |
| :--- | :--- | :--- |
| **Pérdida total de conectividad externa** | Ruta por defecto (0.0.0.0/0) faltante o mal configurada en el Router de borde. | `show ip route` / Verificar gateway de último recurso. |
| **Caída intermitente de la red / Tráfico lento** | Bucles de enrutamiento (Routing Loops) o problemas de rutas asimétricas. | `traceroute` para rastrear el camino salto por salto. |
| **Falta de comunicación entre subredes** | Máscara de subred incorrecta (VLSM mal calculado) o IPs duplicadas en la red. | Revisar direccionamiento del host y comandos `show ip interface brief`. |
| **Vecindades caídas en enrutamiento** | Desalineación de temporizadores (Timers), IDs de área o autenticación en [[OSPF]] o EIGRP. | `show ip ospf neighbor` / Analizar mensajes de [[Syslog]]. |
| **Fallas con aplicaciones pesadas** | Problemas de MTU o tamaño de paquete que requiere fragmentación y tiene el bit DF activo. | Pruebas de ping extendido con comando `ping ip [destino] size [bytes] df-bit`. |

> **Estrategia de Troubleshooting:** Herramientas fundamentales como el ping básico y el traceroute operan sobre el protocolo [[ICMP]], el cual vive en esta capa. Si un host puede hacer ping a su gateway (Capa 2 y Capa 3 local funcionando), pero no puede alcanzar un servidor DNS externo, enfoca tu investigación en las declaraciones de rutas estáticas, políticas de NAT/PAT o en el estado de las adyacencias de los protocolos de enrutamiento dinámico.
