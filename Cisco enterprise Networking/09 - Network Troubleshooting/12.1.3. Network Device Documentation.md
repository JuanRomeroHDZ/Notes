# [[Network Device Documentation|Documentación de Dispositivos de Red]]
Llevar un registro impecable de la infraestructura de red es una de las mejores inversiones de tiempo que se pueden hacer en el área de TI. Más allá de cumplir con un simple estándar, contar con una ficha técnica detallada de cada equipo es el recurso más valioso para agilizar las operaciones diarias y resolver problemas críticos bajo presión sin perder tiempo adivinando.

Cada tipo de dispositivo exige un enfoque de documentación distinto según su función operativa:

 
| Tipo de Dispositivo | Enfoque Principal de Documentación | Datos Críticos a Registrar |
| :--- | :--- | :--- |
| **[[Router\|Routers]]** | Fronteras de enrutamiento, interfaces WAN/LAN y políticas de seguridad perimetral. | Hostname, modelo, versiones de IOS, direcciones IP/IPv6 por interfaz, protocolos de enrutamiento, ACLs. |
| **[[LAN Switch\|Switches LAN]]** | Conectividad de acceso, segmentación local y agregación de enlaces de datos. | Puertos activos, asignación de VLANs, enlaces troncales (Trunks), direccionamiento IP de administración, configuraciones STP/EtherChannel. |
| **[[End-system Documentation\|Sistemas Finales]]** | Servidores, estaciones de trabajo y dispositivos finales que consumen recursos de red. | Sistema operativo, dirección MAC, IP estática/DHCP, puerta de enlace, servidores DNS primarios/secundarios, servicios o aplicaciones críticas alojadas. |
 

## Router Device Documentation
Contar con fichas técnicas de los routers agiliza el diagnóstico de fallas en los enlaces WAN y permite validar rápidamente las rutas hacia redes externas o sucursales remotas.

## End-system Documentation Files
Esta documentación está enfocada en los componentes físicos y lógicos que se utilizan en la administración diaria de la infraestructura, tales como servidores y estaciones de trabajo. 

Una configuración incorrecta o desactualizada en cualquiera de estos componentes puede impactar directamente en el rendimiento global de la red; por esta razón, contar con un registro preciso nos brinda el mejor respaldo para realizar diagnósticos de fallas de manera efectiva cuando se presenten incidentes de software o caídas de servicios.
