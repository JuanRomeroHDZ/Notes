# [[Hierarchical Networks|Redes Jerárquicas]]
Todas las redes deberían ser capaces de cumplir con los siguientes objetivos fundamentales:

*   Soportar aplicaciones críticas.
*   Brindar soporte de tráfico convergente.
*   Adaptarse a diversas necesidades de negocio.
*   Proveer controles administrativos centralizados.

El router de borde de Cisco es una arquitectura que combina innovación y diseño; permite soportar una red de borde que puede ser utilizada para conectarse por cualquier usuario, desde cualquier dispositivo y de manera completamente transparente. También permite el acceso inalámbrico, la aplicación de políticas, el control de acceso y un alto rendimiento a través de diferentes tipos de dispositivos.

Para que sea posible combinar la infraestructura con las políticas, una Cisco Borderless Network provee dos tipos de servicios de configuración:
1. Servicios de red.
2. Servicios de dispositivos finales.

Esto permite a la red trabajar de manera conjunta, facilitando al usuario el acceso a los recursos desde cualquier parte y a cualquier hora, manteniendo la infraestructura optimizada, escalable y segura.

## Principios de Diseño CBN

| Principio de Diseño | Descripción del Objetivo |
| :--- | :--- |
| **Jerarquía** | Facilita la comprensión de la función de cada dispositivo en cada nivel de la red. |
| **Modularidad** | Permite el crecimiento de la red y la adición de servicios sin complicaciones. |
| **Resiliencia** | Garantiza que la red permanezca activa y disponible ante fallos de enlaces o equipos. |
| **Flexibilidad** | Permite compartir la carga de tráfico y usar de forma inteligente todos los recursos del sistema. |

No son los únicos principios, pero comprender cómo encaja cada uno permite crear diseños de redes de manera que se sobreponga la seguridad.

## Capas Críticas del Modelo Jerárquico
En una CBN (Cisco Borderless Network) se cuenta con tres capas críticas, las cuales deben ser vistas como divisiones bien definidas dentro de la infraestructura:

| Capa del Modelo                                  | Función y Conectividad Operativa                                                                                 |
| :----------------------------------------------- | :--------------------------------------------------------------------------------------------------------------- |
| **[[Access Layer\|Capa de Acceso]]**             | Es el punto de entrada de la red donde los dispositivos finales (endpoints) se conectan directamente.            |
| **[[Distribution Layer\|Capa de Distribución]]** | Interconecta los distintos switches de acceso, procesa políticas de red y distribuye el tráfico hacia el núcleo. |
| **[[Core Layer\|Capa de Núcleo]]**               | Funciona como el backbone o columna vertebral de la red, conectando las capas de distribución a alta velocidad.  |
