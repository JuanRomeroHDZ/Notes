# [[Router Requirements|Requerimientos del Router]]
Como se sabe, el router utiliza porciones de prefijos de [[IP]] para enrutar los paquetes. Por lo tanto, es necesario seleccionar el protocolo de enrutamiento más adecuado para determinar el mejor camino para entregar dichos paquetes hacia su destino.
 
| Funcionalidad del Router | Propósito Técnico en la Red |
| :--- | :--- |
| **Conectar geográficamente locaciones** | Interconecta sucursales o edificios distantes a través de redes WAN. |
| **Agrupar usuarios lógicamente** | Segmenta la red mediante subredes o interfaces para organizar los departamentos de la empresa. |
| **Proveer seguridad utilizando filtros** | Controla el flujo de datos y protege los recursos mediante Listas de Control de Acceso (ACLs). |
Comprender estas capacidades esenciales facilita la elección del equipo de enrutamiento adecuado, garantizando que el hardware pueda procesar las tablas de rutas y mantener la comunicación segura entre las distintas oficinas del negocio.
