# [[Switch Form Factors|Factores de Forma de los Switches]]
Al momento de elegir equipamiento es importante considerar qué es lo que buscamos: equipamiento apilable, no apilable, modular, no modular, configurado o no configurado.

Por este motivo, Cisco nos ofrece al menos 4 formas o características de las cuales podemos elegir:

| Factor de Forma                                         | Características Operativas                                                            | Ventaja Principal                                                                   |
| :------------------------------------------------------ | :------------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------- |
| **[[Fixed Configuration\|Configuración Fija]]**         | Puertos y funciones internas predefinidas de fábrica. No admiten expansiones físicas. | Solución económica y lista para implementaciones rápidas.                           |
| **[[Modular Configuration\|Configuración Modular]]**    | Chasis abierto que permite instalar tarjetas de línea (line cards) según se requiera. | Alta escalabilidad y flexibilidad para cambiar interfaces.                          |
| **[[Stackable Configuration\|Configuración Apilable]]** | Switches independientes conectados mediante cables especiales de apilado dedicados.   | Permite operar y administrar múltiples switches como una sola unidad grande.        |
| **[[Switch Thickness\|Espesor del Switch]]**            | Definido por la altura física del equipo en unidades de rack (RU o U).                | Optimización del espacio vertical dentro del rack o gabinete de telecomunicaciones. |
## Fixed Configuration Switches (Switches de Configuración Fija)
Este tipo de equipos normalmente vienen configurados de manera limitada de fábrica con el hardware del propio switch, lo que significa que no se pueden añadir más puertos ni módulos principales de los que ya vienen integrados en el chasis.

## Modular Configuration Switches (Switches de Configuración Modular)
Este modelo permite utilizar switches modulares que ofrecen la capacidad de intercambiar o agregar tarjetas de línea según las necesidades de densidad de puertos o tipos de medios (cobre o fibra) que requiera el negocio.
![[Pasted image 20260612092302.png]]
## Stackable Configuration Switches (Switches de Configuración Apilable)
Este factor de forma utiliza cables de apilado especiales en la parte posterior que permiten interconectar varios equipos físicos, logrando operar y gestionar de manera efectiva múltiples switches independientes como si fuesen un único switch grande.
![[Pasted image 20260612092404.png]]
## El Espesor del Switch (Switch Thickness)
Se refiere a las dimensiones físicas y la altura del dispositivo. Habitualmente se mide en Unidades de Rack (Rack Units o **U**), siendo común encontrar switches de acceso de **1U** de espesor para optimizar la organización y el flujo de aire dentro de los gabinetes.
