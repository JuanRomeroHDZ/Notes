# [[DSL Technology|Tecnología DSL]]
La tecnología de DSL se emplea para poder usar instalaciones de cobre existentes o viejas por donde viajan servicios de IP y VoIP en diferentes frecuencias, las cuales no se interfieren entre sí.

## Separación de Frecuencias
La clave de esta tecnología radica en la multiplexación por división de frecuencias, lo que permite segmentar el medio de cobre:

| Servicio Transportado | Segmentación del Medio | Comportamiento en el Hilo de Cobre |
| :--- | :--- | :--- |
| **Tráfico de Datos (IP y [[VoIP]])** | Frecuencias Altas | Viajan por canales superiores dedicados para el transporte de paquetes a alta velocidad. |
| **Voz Convencional (PSTN)** | Frecuencias Bajas | Utiliza la banda base inferior, permitiendo llamadas telefónicas simultáneas sin interferir con los datos. |
