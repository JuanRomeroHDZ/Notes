# [[Remote Access VPN|VPN de Acceso Remoto]]
Las [[VPN]] de acceso remoto habitualmente permiten a los usuarios crear un túnel a las empresas o servidores, usualmente con un acceso limitado para lograr tareas concretas. Estas conexiones habitualmente se tienen que activar de forma dinámica por el usuario.

## Opciones de Conectividad
Los túneles de comunicación se pueden estructurar a través de dos protocolos principales, permitiendo transportar información de manera segura y sencilla, contando con la paridad del tiempo de respuesta:

| Protocolo de Túnel | Beneficio en Acceso Remoto |
| :--- | :--- |
| [[IPsec]] | Proporciona una suite de seguridad robusta y autenticación profunda a nivel de red. |
| [[SSL]] | Facilita un acceso sencillo, flexible y de rápida implementación para los usuarios. |
